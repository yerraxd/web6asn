# Assignment #6. jQuery (Selectors, Effects, Animations)

## Description

A multi-page website built with HTML, CSS, Bootstrap 5 and jQuery. It demonstrates jQuery selectors, effects, DOM manipulation, animations and a mini project. Every page has the same Bootstrap navbar.

## Pages

| Page | Content |
|------|---------|
| `index.html` | Task 1: Selectors & CSS, Task 2: Visibility Methods |
| `task2.html` | Task 3: Fade Methods, Task 4: Slide Methods |
| `task3.html` | Task 5: Add & Remove Elements, Task 6: Modifying Attributes |
| `task4.html` | Task 7: Form Interaction |
| `task5.html` | Task 8: Basic Animation, Task 9: Sequential Animations, Task 10: Combined Animation |
| `project.html` | Task 11: Mini Project (Image Gallery) |

## Technologies

- HTML5, CSS3
- Bootstrap 5 (navbar)
- jQuery 3.7.1 (CDN)

## How to run

1. Clone the repository.
2. Open `index.html` in a browser.
3. Use the navbar to move between pages.

Live demo: https://yerraxd.github.io/web6asn/
